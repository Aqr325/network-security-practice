## 学习路线

1. **基础网络** — OSI 七层、TCP/IP、DNS、HTTP/HTTPS
2. **Web 安全** — OWASP Top 10、XSS、SQLi、CSRF、SSRF
3. **渗透测试** — 信息收集 → 漏洞扫描 → 利用 → 后渗透
4. **逆向 / 反编译** — Ghidra、x86/ARM 汇编基础
5. **CTF 实战** — Pwn / Crypto / Reverse / Web

> ⚠️ **伦理边界声明**：所有实验仅限授权环境（DVWA、CTF 平台、自建资产），严禁对未授权系统实施扫描/攻击。
