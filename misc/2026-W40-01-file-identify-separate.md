# 文件识别与分离（file 命令 / binwalk）

> 杂项方向 | 第 1 周讲义

 file命令
附件双击打不开，由于出题人经常会故意修改文件名、删除扩展名，或者让文件内容与扩展名不一致。因此，我们不能只相信文件名，而应该检查文件的实际内容。
file 命令是 Linux 系统中一个非常实用的工具，它能够根据文件的内容而非扩展名来判断文件的实际类型。这与 Windows 系统通过文件扩展名来定义文件类型的机制不同，在 Linux 中，用户不能仅凭文件名或扩展名来准确判断文件类型。因此，file 命令对于确保文件处理的安全性和准确性尤为重要。
通过分析文件头部信息中的标识信息来显示文件类型。具体来说，它会执行一系列测试以确定文件是否属于特定类别，如普通文件、目录、字符设备、块设备、符号链接等，并进一步识别出文本文件、二进制文件、可执行文件、压缩文件等多种具体类型。此外，file 还可以用来辨别一些文件的编码格式，这对于处理来自不同来源的数据特别有用。
语法
file [-b/c/L/v/z][-f &lt;名称文件&gt;][-m &lt;魔法数字文件&gt;...][文件或目录...]
-b 　列出辨识结果时，不显示文件名称
-c 　详细显示指令执行过程，便于排错或分析程序执行的情形
-f&lt;名称文件&gt; 　指定名称文件，其内容有一个或多个文件名称时，让file依序辨识这些文件，格式为每列一个文件名称
-L 　直接显示符号连接所指向的文件的类别
-m&lt;魔法数字文件&gt; 　指定魔法数字文件
-v 　显示版本信息。
-z 　尝试去解读压缩文件的内容。
[文件或目录...] 要确定类型的文件列表，多个文件之间使用空格分开，可以使用shell通配符匹配多个文件。
十六进制魔数与文件头修补
十六进制：
计算机中的文件，本质上是由一个个字节组成的。
一个字节有 8 个二进制位，可以表示从 0 到 255 的数值。为了方便查看，我们通常使用两位十六进制数表示一个字节。
为什么
  二进制：最贴近位的表示，但太长，不方便阅读。
  十进制：适合日常计数，但不太适合直观查看字节。
  十六进制：每个字节通常用两个字符表示，紧凑且便于识别
魔数：
文件中用于帮助识别格式的特征字节序列。
很多文件格式会在固定位置放置具有辨识度的字节。最常见的就是文件开头的签名，也就是我们经常说的文件头魔数。
文件头：文件开头的一段数据
魔数：用于识别格式的特征值，通常位于文件头，但也可能出现这其他固定位置
魔数不一定是文件头的全部内容，而且不是每一种文件都具有统一固定的开头签名。
不能只记文件头，因为魔数只是判断格式的线索，不能保证文件完整，能正常打开
Windows上用010可以查看十六进制
Linux下用xxd可查看
 文件头修补
现在有一个gif文件的开头原本应该是：
47 49 46 38 39 61
但是现在是：
00 00 46 38 39 61
前两个字节被修改了。
这时可能发生的情况是：
文件名依然以 .gif 结尾。
图片查看器无法识别文件。
file 无法将它识别为 GIF。
使用十六进制工具发现开头与标准签名不一致。
如果你确认损坏的就是这两个字节，就可以将它们修复为正确值。但要注意，不能看到文件头不匹配就盲目修补。应该先判断真实格式，再对照正常样本或官方格式规范确认正确字节。
可能出现的通常有两种情况
字节被修改
字节被删除：注意要判断缺失字节的数量和位置
Binwalk文件分离
这个文件实际由两部分数据拼接而成。文件分离就是定位隐藏数据的起始位置，并把对应字节提取出来，形成一个独立文件。这种情况也常被称为文件拼接或文件嵌入。
https://www.cnblogs.com/ywrxjry/p/18240106
基本用法：
binwalk [选项] 文件名
参数介绍：
-B：不执行任何提取，只显示可能包含文件的偏移量。
-e：将所有提取文件保存到当前目录下的一个子目录中。
-M：尝试包含另一个已知格式（以逗号分隔的列表）。
-y：尝试所有提取操作/文件类型。
binwalk   文件名          //查看
binwalk -e 要分解的文件名     //-e分解出压缩包
binwalk -D=jpeg/*文件类型*/      要分解的文件名          //-D或者–dd 分解某种类型的文件
binwalk -eM  要分解的文件名              //-M 递归分解扫描出来的文件（得跟-e或者-D配合使用）
